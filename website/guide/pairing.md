# 连接 iPhone

## 连接前确认

- 电脑和 iPhone 的蓝牙均已开启。
- 电脑蓝牙适配器支持 **BLE 外设角色**。仅支持普通蓝牙或 BLE 中心角色并不足够。
- Windows 已安装 WebView2 运行时。

## 配对步骤

1. 打开 SmsPop，在“连接”页点击“添加设备”。
2. 打开 iPhone 的“设置 → 蓝牙”，找到电脑并完成配对。
3. 允许电脑接收 iPhone 通知。
4. 若没有收到授权提示，点击电脑名称旁的信息按钮，开启 **共享系统通知**。
5. 让 iPhone 收到一条新通知，在电脑上确认是否显示。

::: tip 先用一条新通知验证
“本地弹窗测试”只验证电脑上的通知显示和交互，不验证蓝牙连接。
:::

## 离开与重新连接

SmsPop 会在手机离开后自动重试连接，手机返回后重建通知会话。休眠、驱动、系统权限和 iPhone 通知策略仍可能影响接收。

如果已配对但收不到新通知，请查看 [常见问题](./faq)。

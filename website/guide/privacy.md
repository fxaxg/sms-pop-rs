# 隐私说明

## 通知处理

通知传输与验证码识别在本机完成，不需要云端转发服务。经 HTTP 接入时，发送器、代理和所处网络也会影响传输的隐私边界。

## 网络访问

- 正式构建会访问 GitHub Releases 检查和下载更新，不会为此上传通知内容。安装更新需要手动确认。
- “关于”页会从 Shields.io 加载在线徽章。
- 点击配置的 HTTPS 链接或应用协议后，目标浏览器或应用可能访问网络。
- 官网的下载和 GitHub 链接会打开 GitHub；本站没有加入统计脚本。网站随托管服务正常处理访问请求。

## 本地偏好

官网将外观偏好保存在当前浏览器中，用于记住深色或浅色模式。首页通知卡片仅展示虚构的示例验证码，点击“复制”只会将该示例写入剪贴板。

## 反馈与日志

开发版本的日志可能包含通知内容、联系人或验证码。反馈前请脱敏，不要公开上传原始日志或配置文件。

HTTP 接收链接包含凭据，应按敏感信息保管，详见 [网络接入安全边界](./network#安全边界)。

安全问题请按仓库 [SECURITY.md](https://github.com/fxaxg/sms-pop-rs/blob/main/SECURITY.md) 的说明报告。

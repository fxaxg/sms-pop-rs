## 审查与实现取舍

独立审查发现的三项重要问题（休眠过期、运行期间凭据丢失、填入失败后的复制入口）均已增加回归测试并修复。Mac 新增界面的完整多语言支持暂缓。

复用独立克隆的功能分支；平台无关连接元数据抽到 core，因此 Windows 导入路径需要 CI 验证。仓库沿用 Node 22 测试命令，构建工具安装在独立目录，未替换系统 Node 或 shell 配置。任务 1–5 因共享接线合并为一次集成提交，代价是初次审查范围较大。

快捷键单独原子保存，避免设置自动保存覆盖注册状态，代价是增加一个配置文件。输入等待修饰键释放后再次检查候选有效期，接口因此增加有效性回调。

签名公证和特殊多输入框适配未包含在首版交付中；复制作为兼容性回退。自动化测试不能证明手机链路或原生控件接受输入，未完成的检查保留为未验证。

# Android → macOS 局域网验证码：第一版设计

## 目标与范围

用户已选择先支持安卓手机和 Mac 在同一 Wi-Fi 下使用。沿用 SmsForwarder 发送短信，在现有 SmsPop（Tauri 2 / Rust / React）上增加 macOS 支持。成功标准是手机真实收到验证码后，Mac 能收到提示、复制验证码，并由用户主动触发填入。

第一版不开发安卓 App，不部署中转服务器，不提供跨网络传输和 Mac 蓝牙接收。光标旁候选条延后；第一版使用全局快捷键填入焦点输入框。现有 Windows 行为保持兼容。

## 方案选择

采用改造现有 Tauri 应用的方案，复用 HTTP 接收、识别、过滤、去重、设置和通知界面。另一方案是新建 Swift 原生 Mac 应用，可减少跨平台接口适配，但需要重新实现界面和接收链路，暂不采用。

## 用户流程

1. 启动 Mac 应用，在网络接收页启用服务，选择局域网地址并复制接口地址。
2. 安卓安装 SmsForwarder，配置短信 Webhook：POST 到 `/api/v1/notifications`，表单使用 `device_name=Android&from=[from]&content=[content]`。界面提供可直接照填的设置说明。
3. 使用随机令牌鉴权。优先使用 Authorization Bearer 请求头；发送端不能配置请求头时允许现有 token 查询参数。
4. 收到消息后按现有规则提取验证码并弹出不抢焦点的通知。通知支持点击复制，自动复制由用户选择，默认关闭。
5. 用户将焦点放到目标输入框，按默认快捷键 Command+Shift+V 填入最新未过期验证码。快捷键可修改；冲突时明确显示注册失败。
6. 首次填入提示开启 macOS 辅助功能权限；未授权时复制仍然可用。

## 实现边界

- `smspop-core`：保留纯逻辑。验证码候选只驻留内存，自本机接收起 120 秒后失效；无验证码的消息不覆盖有效候选。
- `src-tauri`：按平台隔离 BLE、Windows UIA、窗口坐标、应用启动、系统设置入口、令牌存储和更新逻辑。HTTP 消息处理与 Windows BLE 启动解耦。
- macOS 输入：统一经过用户触发的插入入口，在操作前检查权限和当前焦点；拒绝本应用窗口、只读或无法确认可编辑的目标。通过系统事件输入验证码，不模拟回车、不提交表单。失败提供手动复制入口。
- macOS 第一版不启动光标位置轮询，不创建候选条；Windows 保留既有点击候选条路径。快捷键是用户触发动作，对应仓库原有“绝不自动填入”的约束；实现时同步更新该约定中的入口描述。
- 令牌：macOS 用 Keychain 保存；Windows 保持 DPAPI。Keychain 访问失败时接收服务保持关闭并显示错误，不退化为明文存储。
- 界面：Mac 显示局域网接收引导，隐藏不可用的 iPhone BLE 配对操作；增加权限状态、快捷键配置与候选有效期说明。
- 构建：解除固定 Windows Rust 工具链，按 target 配置系统依赖和打包。Mac 开发构建不连接原项目的更新发布通道。提供本机可启动的开发应用；签名、公证与正式发布另行处理。

## 网络与失败处理

沿用现有 HTTP 参数校验、请求大小限制、限流、鉴权与消息去重。HTTP 仅用于用户信任的局域网，令牌不提供传输加密；说明页明确这一点，不将接口暴露到公网。

同一 Wi-Fi 仍可能存在客户端隔离，说明页提供手机到 Mac 的连通性排查步骤。Mac 防火墙需允许应用入站，端口冲突或绑定失败在界面显示。IP 变动时更新接收地址并提示重配。电脑休眠或应用退出时不能接收；不承诺离线补发。

正文、验证码和令牌不写日志或历史文件。令牌重置立即使旧配置失效。快捷键无有效候选时不输入任何内容；权限被撤销或目标不可写时报告失败，不宣称填入成功。

## 验证与交付

自动检查覆盖：现有验证码提取及过滤回归、候选过期、鉴权失败、合法表单/JSON、重复消息、非法和超长请求、令牌重置。运行 Rust 相关测试、格式检查、Clippy、前端测试和构建，以及 macOS 应用构建。Windows 平台需 CI 或 Windows 环境验证，不能用 Mac 构建替代。

本机交互验证：启动应用，模拟 POST，观察弹窗与复制；验证权限未授予时的提示；授权后验证 TextEdit 及实际使用浏览器的单输入框填入。多格验证码与特殊控件不预先承诺兼容，无法填入时保留复制。

用户参与真机验收：手机配置 SmsForwarder 并接收一条实际验证码，检查接收、复制和快捷键填入；核查手机后台权限、防火墙和网络隔离。模拟 POST 成功不等于真机链路通过。

交付包含修改后的源码、可启动的 Mac 开发构建及手机配置/权限/故障排查说明。当前已完成源码调研；尚未开始实现。本机 PATH 未发现 cargo/rustc，实现阶段需准备 Rust stable 工具链。
